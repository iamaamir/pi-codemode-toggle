Toggle Codemode in Pi.

Codemode lets Pi handle several tool steps together instead of one at a time. Type /codemode to switch it on, type it again to switch it off. No restart, no settings to edit.

$ pi install npm:pi-codemode-toggle

Reference

What is Pi Codemode?

Codemode is Pi's built-in mode in which the model emits a small Javascript program that calls your tools, rather than issuing one tool call per step. Pi ships it as the builtin:codemode extension; this package gives you runtime control over it.

How to enable codemode in Pi
  1. Install the extension: pi install npm:pi-codemode-toggle
  2. Type /codemode or /codemode on in a session
  3. Type /codemode off to switch it back
  4. The footer indicator reads codemode:on or codemode:off
Commands
Commands accepted by /codemode
Command Effect
/codemodeToggle Codemode on or off
/codemode onEnable Codemode
/codemode offDisable Codemode
/codemode statusReport the current state

Argument completions are provided for on, off, status and toggle.

Troubleshooting

/codemode missing after install is almost always project trust. pi install npm:pi-codemode-toggle -l writes the declaration to the project's .pi/settings.json, which Pi only reads once that folder is trusted. Install without -l to add the package to ~/.pi/agent/settings.json, or grant trust to the directory. Confirm with pi list.
